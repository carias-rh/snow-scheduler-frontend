How It Works

Add an ICS feed URL from any calendar provider (Google Calendar, Outlook, Nextcloud, public holiday feeds) or a local file path to an .ics file. The app polls the source and auto-toggles PTO for members whose names appear in event titles. Use "Match by email" if events use attendee addresses instead.
